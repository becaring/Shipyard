## Historical code with the conditional notice

The maintained identity is `becaring/Re60-Legacy-Xenos-Renderer` commit `23eb15e6bee171d6c1c2bd38350d222bedff0d4c`; becaring is the current maintainer. Its `LICENSE.txt` is SHA-256 `7cba45a713b4323620d6c97e44d7ca5f59a262abddfb9d0f930410b9acbf29d8`. The full text permits binary redistribution only when the binary contains no assets the distributor lacks rights to distribute, and requires its notice/disclaimer. Its `README.md` identifies `gfx_cc.cpp` and the shared shader formula lineage as upstream Fast3D material, `gfx_xdk_shader.cpp` as an SM3 adaptation, and `gfx_xdk.cpp` as the local Xenos backend. The shader file itself marks `shader_item_to_str` and `append_formula` as Direct3D combiner formula logic carried from upstream. The Git blobs are `d614b1b24711e81b7ccf0e597fb0220486a627b0` (`gfx_cc.cpp`), `d30deb80f6f067c50b47495ade121de2474979c9` (`gfx_xdk_shader.cpp`), and `51340f49dfba1c1877450e56909fc1010b26d4ca` (`gfx_xdk.cpp`). The conditional notice governs that historical mixed-origin snapshot; it is not a grant automatically attached to a later file merely because it is called Fast3D.

The older SoH360 snapshot has a different 19-line upstream Fast3D notice, SHA-256 `2664ed6c027782b6264c2db874a2e894417eaa0f2494212d77462dff8bce55ec`, with source redistribution and no binary exception. The later official Emill notice at `881eb68bad1150f720433d75bccb4d26879c28ab` is byte-equivalent to the conditional text above after line-ending normalization. These texts remain distinct evidence of their respective revisions.

## Disposition and limit

R1 is closed for the *selected source inputs*: the actual Fast3D-derived interpreter, combiner and projected shader formula are identified as upstream code under the two active pinned MIT notices, while the Shipyard-specific backend and mechanisms have the maintainer's local source trail. The old source-only notice and later conditional asset exception are retained for their historical revisions; neither was silently substituted for the active MIT grant. No historical Re60 `gfx_xdk.cpp`, `gfx_xdk_shader.cpp`, or `gfx_cc.cpp` is selected for the current XEX builds.

The comparison is a bounded source/manifest/implementation review, not a claim that low exact-line overlap proves independent authorship. A specific new source match showing protectable historical expression in one of the named current files would require reopening that file's notice assignment. No such unmatched portion was identified in this selected-input trace. Asset rights and any condition on a proposed release payload remain R3; Modern's statically linked eSpeak obligations remain R2; consumer game/decomp source remains R5.
